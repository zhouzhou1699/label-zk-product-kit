# 术语表与指标字典

## 一、术语表（中英对照 + 产品内精确定义）

| 中文 | 英文 / 代码 | 定义 | 易混淆点 |
|---|---|---|---|
| 单位 | Institution | 数据边界。企业/院校实体，独占存储配额、OSS、模型配置、品牌 | ≠ 团队。单位之间完全不可见 |
| 团队 | Organization | 单位内的工作组织，角色授权与审批的作用域 | 团队可有多个空间 |
| 空间 | Workspace | 团队下的项目容器；分个人空间/团队空间/未分组/归档 | 个人空间仅本人可见，只用于自训 |
| 项目 | Project | 一次标注任务完整单元 = 标注配置 + 任务 + 发布状态 + 项目角色 | 标注模式创建后不可改 |
| 任务 | Task | 一条待标注数据条目，有独立状态与归属 | 一任务可有多份标注（多人同标） |
| 标注 | Annotation | 对任务的一次标注结果（result 数组 + 元数据） | 草稿也是 annotation，但 status=drafting |
| 预测 | Prediction | 模型产出的结果，可作预标注或对比基线 | 预标注默认只是建议，需人工确认 |
| `label_config` | — | 项目的 XML 标注配置，决定界面/模型可用性/导出格式 | **改它会可能让历史标注失效** |
| 视图 | View | 数据页保存的"列+筛选+排序"组合，URL `?tab=<id>` | 分享链接带上 tab 才是同一视图 |
| 一审 | Review | 质检员把关，通过或打回 | 一审通过**不发积分** |
| 终审/验收 | Validation | 验收员给评分 + 结论 | **唯一结算点** |
| 打回 | Reject | 审核或验收退回，计入 `reject_count` | 归属人不变（不会被别人抢走） |
| 验收台账 | Validation Ledger | 按任务记录验收人/结论/评分的 CSV | **不是**标注结果 |
| 预标注 | Pre-annotation | 用模型先填一版，人工修正 | 采纳率是新指标（v2.2） |
| 多人同标 | Overlap / Consensus | 同一任务多人分别标注，用于交叉校验 | 由 `maximum_annotations` 控制 |
| 私有货架 | Private Shelf | 模型超市里属于本单位的模型区 | 训练产物自动进入 |
| 积分 | Points | 通过任务后按公式结算的奖励，非货币 | 只在终审通过时结算一次 |
| 证书 | Certificate | 达标后颁发的 PDF 凭证，属某项目 | 一次性颁发，不重复 |
| 分发 | Distribute | 把数据集共享给其他团队/下级单位 | 引用而非复制，不占双倍存储 |
| 交付率 | Delivery Rate | `passed / total` | 平台当前 3.9% |
| 打回率 | Reject Rate | `rejected / submitted` | 目标 ≤5% |

## 二、指标字典（单一事实来源）

> 约定：每个指标必须声明 `scope`。UI 上必须显示 scope chip。
> 服务端建议提供 `GET /api/metrics/definitions` 返回下表。

### 2.1 规模类

| key | 名称 | 公式 | scope | 数据源 |
|---|---|---|---|---|
| `institutions.total` | 单位总数 | `count(Institution)` | PLATFORM | institutions |
| `orgs.total` | 团队总数 | `count(Organization)` | PLATFORM | organizations |
| `workspaces.total` | 空间总数 | `count(Workspace)` | PLATFORM | workspaces |
| `projects.total` | 项目总数 | `count(Project)` | TEAM / INSTITUTION / PLATFORM | projects |
| `tasks.total` | 任务总数 | `count(Task)` | PROJECT / TEAM / PLATFORM | tasks |
| `members.total` | 成员数 | `count(distinct User in scope)` | TEAM / INSTITUTION / PLATFORM | memberships |
| `datasets.total` | 数据集数 | `count(Dataset)` | INSTITUTION / PLATFORM | datasets |

### 2.2 流程类（核心）

| key | 名称 | 公式 | 说明 |
|---|---|---|---|
| `pipeline.unclaimed` | 待领取 | `count(Task where status=unclaimed)` | |
| `pipeline.working` | 标注中（无草稿） | `count(Task where status=working)` | **v2.1 新增** |
| `pipeline.drafting` | 标注中（有草稿） | `count(Task where status=drafting)` | **v2.1 新增** |
| `pipeline.pending_review` | 待审核 | `count(Task where status=pending_review)` | |
| `pipeline.pending_validation` | 待验收 | `count(Task where status=pending_validation)` | |
| `pipeline.passed` | 已通过 | `count(Task where status=passed)` | |
| `pipeline.rejected` | 已打回 | `count(Task where status=rejected)` | |
| `pipeline.in_flight` | 在途 | `working + drafting + pending_review + pending_validation` | 别与"已标注"混用 |
| `delivery.rate` | 交付率 | `passed / total` | 分母为全部任务 |
| `delivery.net_backlog` | 净积压 | `(新增任务 − 通过任务)` 近 7 天 | 负数 = 在消化 |

### 2.3 时间类（v2.2 新增）

| key | 名称 | 公式 |
|---|---|---|
| `cycle.time.p50` | 任务周期中位数 | `median(passed_at − claimed_at)` |
| `cycle.time.p90` | 任务周期 P90 | `p90(passed_at − claimed_at)` |
| `stage.dwell.review.p50` | 审核停留中位数 | `median(reviewed_at − submitted_at)` |
| `stage.dwell.validate.p50` | 验收停留中位数 | `median(validated_at − reviewed_at)` |
| `draft.age.p50` | 草稿年龄中位数 | `median(now − draft_updated_at where drafting)` |
| `annotation.active_time.p50` | 标注活跃时长中位数 | 前端心跳聚合（排除空闲 >5min） |

### 2.4 质量类

| key | 名称 | 公式 |
|---|---|---|
| `quality.reject_rate` | 打回率 | `rejected_events / submitted` |
| `quality.reject_rate.by_reason` | 按原因分布 | `group by reason_code` |
| `quality.avg_rating` | 平均质量分 | `avg(validation_rating)` |
| `quality.consistency.kappa` | 一致性（分类） | Fleiss' κ |
| `quality.consistency.miou` | 一致性（分割） | mean IoU between annotators |
| `quality.gold.pass_rate` | 金标准通过率 | `gold_passed / gold_total` |
| `quality.outlier.annotators` | 离群标注员数 | 一致性低于整体 2σ 的人数 |

### 2.5 激励类

| key | 名称 | 公式 |
|---|---|---|
| `points.balance` | 当前积分 | `sum(PointsTransaction.points)` |
| `points.month_earned` | 本月新增 | 本月流水正数之和 |
| `points.per_task.avg` | 单任务平均积分 | `sum(points)/count(passed)` |
| `points.reject_penalty.total` | 打回扣分总额 | `sum(negative points where type=reject)` |
| `certificates.issued` | 已发证书 | `count(Certificate)` |

### 2.6 模型类

| key | 名称 | 公式 |
|---|---|---|
| `model.on_shelf` | 在架模型 | `count(market status=active)` |
| `model.map50.avg` | 平均 mAP50 | `avg(map50)` |
| `model.preanno.adoption` | 预标注采纳率 | `unchanged_pred_regions / all_pred_regions` |
| `model.preanno.correction` | 修正率 | 修改过的区域数 / 全部 |
| `model.preanno.deletion` | 删除率 | 删除的预标注区域 / 全部 |
| `model.deploy.projects` | 部署项目数 | `count(distinct project)` |
| `model.hardcase.pool` | 难例池规模 | `count(HardCase)` |

## 三、术语禁用清单（文案规范）

| 禁用 | 替换为 | 原因 |
|---|---|---|
| 完成 / 已完成 | 已通过（终审）/ 已标注 | "完成"同时被用于两种含义，是口径混乱根源 |
| 数据量 | 任务数 / 文件数 / 字节数 | 三者不可混用 |
| 模型精度 | mAP50 / mAP50-95 / 准确率 | 必须指明指标 |
| 审核（泛指） | 一审（质检）/ 终审（验收） | 两个环节责任不同 |
| 删除（数据集） | 归档 / 彻底删除 | 需要区分可恢复性 |
| 上线（模型） | 上架（货架）/ 部署（项目） | 两个动作不同 |

## 四、时间与数字格式规范

| 类型 | 格式 | 示例 |
|---|---|---|
| 绝对时间（详情/导出） | `YYYY-MM-DD HH:mm` | `2026-11-14 13:50` |
| 相对时间（列表） | `x 分钟前 / x 小时前 / x 天前`，>7 天转绝对 | `3 小时前` |
| 日期（仅日期） | `YYYY-MM-DD` | `2026-11-14` |
| 大数字 | 千分位；≥10 万用 `万` | `4,825` / `12.8 万` |
| 百分比 | 保留 1 位小数，<0.1% 显示 `<0.1%` | `3.9%` |
| 文件大小 | `KB/MB/GB`，保留 1 位 | `2.8 GB` |
| 积分 | 整数 + `分` | `403 分` |
