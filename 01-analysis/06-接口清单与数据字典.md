# 接口清单与数据字典（实测 61 个端点）

> 全部通过浏览器真实会话抓取，状态码为实测值。`503` 表示该端点未部署或依赖服务异常（平台统一错误码）。
> 鉴权：`Cookie: sessionid=…` + `X-CSRFToken`；`X-Requested-With: XMLHttpRequest`。

## 十、性能与工程质量观察

| 观察 | 影响 | 建议 |
|---|---|---|
| `/api/current-user/whoami` 返回 **28.7 KB**（携带全量 `custom_hotkeys`） | 每个页面都请求，首屏成本无谓增加 | 拆分为 `/whoami`（轻）+ `/preferences`（重，懒加载） |
| `/api/templates` **154 KB**、`training/overview` **156 KB**、`market/models` **18 KB 不分页** | 移动端/弱网首屏慢；无法局部刷新 | 分页 + `fields=` 投影（项目接口已用 `include=`，说明团队知道怎么做，只是没推到全部接口） |
| 路由不存在也返回 503 | `/datasets/new` 直链白屏，排障困难 | 区分 404 / 5xx；SPA 加 `errorElement` |
| 大量 `503` 端点（导出历史、云存储直传、云导出设置） | 界面上有入口但功能未通 | 用 feature flag 隐藏，别让用户看见"点了报错"的按钮 |
