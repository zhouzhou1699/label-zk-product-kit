# 竞品对标与差异化分析

> 对标对象：Label Studio（开源底座）、Scale AI / Labelbox（海外标杆）、国内标注 SaaS（百度众测/阿里众包类、龙猫数据、BasicFinder）、以及"自建标注团队 + 内部工具"路线。

## 二、Label ZK 的真实定位

**它不是"更好的标注工具"，而是"标注产能的中台"。** 三句话讲清差异：

1. **对标 Label Studio**：LS 是"标注引擎"，ZK 是"标注工厂的 ERP"。ZK 保留了 LS 的 `label_config` 与 DM，但把 LS 缺失的**组织、流程、结算、模型**四层补齐了。这层补齐才是商业价值——客户买的不是画框工具，是"这批数据谁负责、能不能审计、花了多少钱"。
2. **对标 Labelbox**：Labelbox 强在"标注-训练-评估"的实验管理（Model Foundry），弱在**人员管理与计件**（它默认你的人是雇员，不解决产能结算）。ZK 反过来：**人是最重要的资源**，所以有积分、证书、排行、申请审批。这符合中国市场的交付形态（院校实训 + 外包团队）。
3. **对标国内外包标注公司**：外包公司卖人力，ZK 卖"人力 + 工具 + 模型"。差异点在**数据不出单位**（私有化部署 + 单位级 OSS），这是政企/院校客户的硬门槛。

## 三、SWOT

| | |
|---|---|
| **S 优势** | ① 全链路闭环（数据→标注→训练→模型→预标注）；② 组织与结算做得比开源深；③ 已有真实行业落地（工业质检 320+ 产线、校园 192 台设备、茶叶工控）；④ 私有化 + 单位级隔离，符合政企合规；⑤ 内置 15 章产品手册，交付成本低 |
| **W 劣势** | ① 双前端架构（React + LS iframe），体验割裂、升级耦合；② 指标口径不统一，信任成本高；③ 大量 503 端点暴露给用户；④ 登录安全薄弱（验证码可绕、无 MFA）；⑤ 无移动端；⑥ 文档与实现漂移 |
| **O 机会** | ① 模型→产能的 ROI 度量（预标注采纳率/单任务成本）无人做好，是差异化金矿；② 院校市场（实训模式已就位，可做"教学版"独立售卖）；③ 标注质量基准集（用平台历史数据训"金标准"，做质量认证）；④ 开放 API/SDK 做生态（已有 personal token） |
| **T 威胁** | ① Label Studio Enterprise 降价下沉；② 大模型"少样本/零样本"降低标注需求（但质检类高精度场景仍刚性）；③ 客户自建（LS + 自研脚本）成本越来越低；④ 数据合规监管趋严，跨单位分发链路需可审计 |

## 四、可借鉴的三处（来自竞品）

| 竞品做法 | 借鉴点 | 落到 ZK |
|---|---|---|
| Labelbox **Consensus / Benchmark** | 多人同标不止于"人数"，而是给"一致性分数"和"金标准通过率" | ZK 有 `maximum_annotations` 与 `overlap_cohort_percentage`，但没有一致性指标页 → 补一个「一致性看板」（Krippendorff's α / IoU 均值） |
| Scale AI **Quality SLA + 赔付** | 把质量标准写进合同条款，用数据说话 | ZK 有验收台账 CSV，但没有"批次质量报告" → 导出时附带一页质量摘要（漏检率/打回率/一致性），直接可交给客户 |
| LS Enterprise **Active Learning loop** | 不确定性采样 → 只标"模型最不确定的" | ZK 已有 `Uncertainty sampling` 选项，但没有"这一轮省了多少标注量"的对比 → 在数据统计页加"主动学习收益"卡 |

## 五、不该学的地方

- **不要学 Labelbox 的"实验管理"全套**：ZK 的客户是"要交付"不是"要发论文"，加 MLOps 复杂度会拖垮交付节奏。
- **不要学众包平台的"抢单大厅"**：ZK 的模式是"任务归属人固定"，抢单会破坏打回后归属不变的设计。

## 六、结论：三条护城河建议

1. **深挖"可审计"**：审计日志目前有 `audit.view`，但界面未见完整入口。把"每一次标注变更可追溯到人+时间+前后值"做成卖点，政企客户愿意为此付溢价。
2. **把院校做成独立产品线**：实训模式（多人同标 + 不计积分 + 评分）本质是"教学评测系统"，可以单独卖给院校，且是天然的人才漏斗（学生→标注员）。
3. **用数据资产化讲故事**：数据集可分发、可引用、可版本化（当前缺版本）——补上"数据集版本 + 血缘（哪个模型用哪版数据训的）"，就能支撑"数据资产入表"的合规叙事。
