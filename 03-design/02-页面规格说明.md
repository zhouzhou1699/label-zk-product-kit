# 页面规格说明（给 UI 与前端）

> 每个页面给：目的 · 布局栅格 · 组件清单 · 状态（加载/空/错误）· 交互要点 · 验收要点
> 与真实截图对照看：`05-assets/screens/` 同名序号。

---

## 01 登录页 `/user/login/`

- **目的**：品牌第一印象 + 单次身份验证。
- **布局**：左右 55/45 分栏。左侧品牌列（主标题 40px 渐变关键词 + 三条价值卡），右侧 420px 登录卡。
- **组件**：Logo、价值三卡（01 ISOLATION / 02 WORKFLOW / 03 REUSE）、邮箱、密码、7 天自动登录、忘记密码、**拼图验证码**、登录按钮、注册链接、邀请链接提示。
- **状态**：
  - 加载：验证码区显示骨架 + "拼图加载中…"
  - 失败：卡片内 InlineAlert（`请先将拼图拖至缺口处。`）、验证码自动换图（700ms 红色反馈后）
  - 锁定：显示"尝试次数过多，请 14 分 32 秒后重试"
- **交互**：滑块支持键盘（←/→ 1px，Shift 10px，Enter 提交）；验证成功显示 ✓ 并锁定滑块。
- **验收**：ticket 不含明文 offset；失败 5 次锁定。

## 02 首页 `/`

- **目的**：回答"我和我单位现在什么规模、下一步做什么"。
- **布局**：欢迎条（单位名 + 两个 CTA）→ 4 张 StatCard（团队/账号/项目/数据集，**带 scope chip**）→ 公告 + 快捷入口（2 栏）。
- **组件**：WelcomeBar、StatCard×4、NoticeList、QuickEntry×4。
- **改造**：StatCard 加 scope；CTA 从两个降为一个主 + 一个次；公告空态改"发布公告"引导。

## 03 数据大屏 `/dashboard`

- **目的**：投屏级运营总览。
- **布局**：深色主题；顶部 6 个 KPI 块（单位/团队/空间/项目/任务/成员 + 今日新增）→ 左 2/3 增长趋势折线（7 天/12 月，四系列可切换）→ 右 1/3 交付率环形（已通过/审核中/已打回/进行中）→ 下三栏（项目类型环 / 数据集构成环 / 活跃团队条形）。
- **交互**：刷新、全屏、系列切换、58 秒自动刷新（可暂停）。
- **改造**：KPI 加 scope；交付率旁加"瓶颈环节"一句话结论；时间格式统一。

## 04 项目列表 `/projects`

- **目的**：选项目、看积压。
- **布局**：左 240 空间树（全部/个人/团队/未分组/归档 + 搜索）｜右：4 StatCard（项目总数/项目类型/发布状态/生产流水线）+ 存储条 + 工具条（搜索/类型/状态/视图切换）+ 卡片网格（默认 30/页）。
- **卡片规格**（v2 紧凑化）：
  ```
  [图标] 项目名          [已发布] ⋯
  通过率 0%  ▮▮▮▮▮▮▮▮▮▮  (绿0/蓝8/灰22)
  待领取 22 · 标注中 8 · 待审核 1 · 已通过 0
  [头像] 刘成龙 · 2026-11-14
  ```
  六态明细移入 hover 浮层/展开态。
- **状态**：空（无项目）→"创建第一个项目，从 30 条数据开始"；存储超 80% → 黄色 InlineAlert。

## 05 项目工作台 · 任务管理器 `/projects/:id`

- **目的**：干活的总控台。
- **布局**：面包屑 → 页签（1 角色设置 2 设置 3 奖励 4 项目发布 ｜ 数据统计 数据导出 任务管理器）→ 身份切换条（segmented）→ 提示条 → 任务表（缩略图/任务ID/变更时间/标注员/标注状态/审核状态/验收状态）。
- **改造**：
  - 状态列改用 StatusPill（统一色板）。
  - `drafting` 单独可筛；滞留 >24h 行加左黄条 + `草稿滞留` pill。
  - 勾选后浮出批量条（领取 / 释放 / 重新分配 / 重置）。
- **交互**：点行进作业页；`j/k` 上下、`Enter` 打开。

## 06 标注工作台 `/projects/:id/data?task=:tid`

- **目的**：标注/质检/验收的主战场。
- **布局**：顶部工具条（操作/列/筛选/排序/标注全部任务/导入/导出）+ 左任务列（缩略图+序号，可在页面内切任务）+ 中画布（浮层工具：指针/平移/放大/框/画笔/关键点）+ 标签快捷键条 + 右面板（信息/验收/历史）+ 右下面板（区域/关系）+ 底部（任务ID/撤销/重做/删除/缩放/更新/提交）。
- **改造（只改壳，不改画布行为）**：
  - 顶部加统一面包屑 + 「返回任务管理器」（现为右上小按钮）。
  - 「提交」按钮改 `--brand-primary`；「更新」改 Secondary。
  - 右面板加第 4 页签「打回历史」（显示历次打回原因分类 + 前后对比开关）。
  - 离开拦截：有未提交变更时弹确认。
- **状态**：上游 502 → 画布区显示"标注服务暂时不可用"+ 重试 + 追踪 ID，其余壳保持可用（可看任务列表与历史）。
- **验收**：`shift+1` 适应窗口、`Ctrl+滚轮` 缩放、数字键切标签 均保持。

## 07 角色设置 `/projects/:id/roles`

- **目的**：开工前把人配齐。
- **布局**：前置条件卡（4 项，带 ✓ 与「查看」）→ 角色配置三行（标注员/质检员/验收员，各显示人数 + 头像组 + 「设置成员」）→ 流程进度条（标注 → 质检 → 验收）。
- **改造**：每行加一句"建议由不同人承担"提示（终审人=标注人时给黄色警示）。

## 08 项目设置 `/projects/:id/settings`

- **目的**：项目级配置。
- **布局**：左竖向 tab（通用/标注界面/标注/模型/预测/Webhook/危险操作）｜右表单。
- **要点**：顶部固定"标注模式创建后不可更改"提示条；危险操作区三项各带说明 + 输入项目名确认。

## 09 数据统计 `/projects/:id/stats`

- **目的**：这个项目健康吗。
- **布局**：6 张 KPI（总任务/已通过/在途/待领取/已打回/进度）→ 任务进度条（分段）→ 六态数据分布 → 参与成员统计表。
- **改造**：加 ETA 卡（"预计完成 12-05，乐观 11-28 / 悲观 12-18"）+ 瓶颈提示。

## 10 数据导出 `/projects/:id/export`

- **目的**：交付。
- **布局**：导出范围（仅已完成/全部/按数据集/仅我的）→ 流程状态（全部/已通过/待验收/已打回）→ 格式卡列表（按 `label_config` 动态，含说明与外链）→ 云存储直传（目录前缀）→ 后台导出 + 导出历史。
- **改造**：格式列表为空时给**原因**（"本项目标注配置不含可导出目标格式"）+ 修复入口；加"附质量摘要"开关。

## 11 项目发布 `/projects/:id/publish`

- **目的**：把任务放给标注员。
- **布局**：发布状态卡（状态/发布时间/可领取/已领取）→ 发布前四项检查（✓/✗ + 「查看」）→ 发布记录时间线 → 撤回按钮（含"不删数据"说明）。
- **保留**：这是全站最好的页面，几乎不用改。

## 12 项目奖励 `/projects/:id/rewards`

- **布局**：总览（已发积分/已发证书/参与人数/我的排名）→ 成员积分榜 → 「规则与证书」页签（积分公式参数 + 证书规则）。

## 13 数据集库 `/datasets`

- **布局**：左分类树（五大类 + 子类 + 行业分类，带数量）｜右：筛选（团队/可见性/分发/内置/已删除）+ 表格（名称/分类/团队/创建者/可见性/文件数/大小/更新时间/操作）+ 批量操作。
- **改造**：分类树搜索框（47 节点已超一屏）；表格"可见性"用 chip；空态引导"上传第一个数据集"。

## 14 新建数据集（弹层）

- **规格**：560 宽；名称* / 可见性（**卡片式四选**）/ 归属团队* / 分类*（可搜索下拉）/ 描述 / 封面图。
- **改造**：可见性改卡片（私有/团队/单位/公开，各一行副标题），详细规则进 `?`。

## 15 训练集库 `/model-factory/training-sets`

- **布局**：左分类（检测 8 / 分割 3 / 分类 4 / 姿态 3）｜右表格（名称/任务/类别数/训练张数/验证张数/来源/最近迭代/训练按钮）。
- **改造**：来源列"本机目录"改成可读资源名；加"含难例"标记（v2.2）。

## 16 模型训练 `/model-factory/training`

- **布局**：集群卡（型号/在线卡/今日 GPU 时/VRAM）→ 4 KPI（运行中/排队/本周 GPU 时/平均 mAP50）→ 实时曲线（0.9s 刷新）→ 训练任务表 → 快速开始表单（数据集/基座/轮次/批量/设备）。
- **改造**：曲线加"暂停自动刷新"；任务表加"训练耗时 vs 基准"Δ 列。

## 17 模型超市 `/model-factory/market`

- **布局**：Hero（标题+搜索+热门标签）→ 本周精选大卡 → 4 KPI（在架/累计下载/认证供应商/平均 mAP50）→ 分类 tab + 排序 → 模型卡网格 → 「下架的模型」子页。
- **改造**：卡片多选 → 对比表；卡片加"平台采纳率"；下架区入口做成次级 tab 而非按钮。

## 18 模型详情（抽屉 520）

- **内容**：基本信息表（供应商/任务类型/许可/体积/参数量/框架/训练数据/设备/轮次/类别/权重/精度/延迟）→ 基准评测条（mAP50、mAP50-95、类别数）→ 版本记录 → 底部「下载权重」「部署到项目」。
- **改造**：加"近 30 天预标注采纳率"与"部署项目数"。

## 19-22 模型应用（5 个行业方案）

- **定位**：内容型落地页（Hero KPI → 能力矩阵 → 模型表现 → 部署流水线 → 典型场景 → 可用模型）。
- **改造**：从后台导航移出（或拆出"行业控制台"独立入口），页尾加"联系我们"表单而非只给文字。

## 23 积分 `/rewards/points`

- **布局**：项目切换 + 期间筛选 → 4 KPI（当前积分/通过任务数/平均质量分/组织排名）→ 我的项目奖励（按项目卡片）→ 积分流水表 → 组织排行榜。
- **改造**：流水行可展开显示构成（基础/评分/首稿/扣分）；项目卡显示"距下一张证书还差 N 分"。

## 24 我的证书 `/rewards/certificates`

- **布局**：筛选（项目/状态）→ 证书墙（缩略图网格，点击预览 PDF）→ 规则提示。
- **改造**：空态给"如何获得第一张证书"（对应项目的规则）。

## 25 证书中心 `/certificate-center`

- **布局**：左模板列表 + 新建；右 PDF 实时预览（A4 横向 297×210mm）。
- **规格**：模板字段 name/title/subtitle/body_text(支持 `{user_name}`/`{project_title}`/`{points}`)/issuer/level(gold,silver,bronze)/accent_color/background_preset(如 navy-gold)/layout(elements 坐标)。

## 26 组织管理 `/members`

- **布局**：4 页签（单位管理/团队管理/个性化设置/首页装扮 | 云存储 | 模型配置）+ 4 StatCard + 单位表格。
- **改造**：表格一行一信息（层级 chip / 管理员 / 注册时间分三列）；配额条常显。

## 27 申请审批 `/organization/requests`

- **布局**：状态分组（全部/待审批/已通过/已驳回/已撤回/待启用单位）+ 目标单位筛选 + 列表。
- **改造**：批量通过/驳回；驳回必须选原因（复用打回理由组件的模式）。

## 28 系统管理 `/rbac`

- **布局**：左角色列表（内置 9 + 自定义）｜中权限矩阵（26 类 × 权限码，三态：允许/不设置/拒绝）｜右角色资料 + 效果预览（绿=新增可见，红划线=移除）。
- **改造**：矩阵加搜索；「放弃变更」与「保存」固定在底部；显示"此角色当前持有 75 项权限"。

## 29 超管设置 `/platform-settings`

- **布局**：左 tab（登录页/企业空间/问题反馈/工作台·即将开放/通知·即将开放）｜右：登录页品牌（主图 + 标题 + 副标题 + 实时预览）；企业空间（按单位配额表）；问题反馈（队列）。
- **改造**："即将开放"的 tab 不要可点（灰显 + tooltip），别让用户点进去看空页。

## 30 标注操作说明 `/manuals/annotation`

- **形态**：iframe 内嵌 15 章 HTML 手册（2.9 MB 单文件）。
- **改造**：左侧加章节导航（当前只有长页滚动）；手册数字改为构建期注入。
