# 设计系统规范 · Label ZK v2

> 目标：把现有**三套视觉语言**（外壳浅蓝玻璃拟态 / 标注页 Label Studio 沙色 / 大屏深蓝）收敛为**一套 token + 两个主题**。
> 事实基础：token 值取自实测 CSS（`--color-*` 259 个变量）与界面取色；不改动 Label Studio 的画布交互行为。

---

## 一、设计原则

1. **数据优先**：界面上任何装饰都不能压过数字。玻璃拟态只用于"欢迎区 / 空状态 / 弹层背景"，不用于数据表格。
2. **状态即信息**：六个任务状态各有固定色与固定名词，全站不得换色或换词。
3. **可解释的禁用**：按钮/卡片被禁用时必须写出原因（例："这个项目没有矩形框控件，无法输出框"）。**这条是本产品最好的设计，必须制度化。**
4. **一屏一个结论**：每个页面标题下必须有一句"这个页面回答什么问题"（现有产品已做到，保留）。
5. **保守的动效**：150–200ms、`cubic-bezier(.2,.8,.2,1)`；不做视差、不做滚动动画。

## 三、字体与排版

| Token | 值 | 说明 |
|---|---|---|
| `--font-sans` | `"Figtree", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif` | 平台现有 Figtree + 中文回退 |
| `--font-mono` | `"JetBrains Mono", Monaco, monospace` | ID、坐标、代码、路径 |
| `--fs-display` | 40/44 · 700 | 登录页主标题、大屏 KPI 大数 |
| `--fs-h1` | 26/34 · 700 | 页面标题（"标注项目"） |
| `--fs-h2` | 20/28 · 600 | 区块标题（"增长趋势"） |
| `--fs-h3` | 16/24 · 600 | 卡片标题 |
| `--fs-body` | 14/22 · 400 | 正文（全站基准） |
| `--fs-sm` | 13/20 · 400 | 表格、说明 |
| `--fs-xs` | 12/18 · 500 | 标签、chip、时间戳 |
| `--fs-mono` | 13/20 · 500 | ID、坐标 |

**排版规则**
- 数字用 `font-variant-numeric: tabular-nums`（表格与 KPI 对齐）。
- KPI 大数字：`--fs-display` + `--brand-gradient` 文字渐变（大屏），浅色主题用 `--text-primary`。
- 中文标题不加字间距；英文全大写小标题加 `letter-spacing: .08em`（如 `DATA ANNOTATION PLATFORM`，现有产品已用，保留）。

## 五、组件规范（12 个核心组件）

### 5.1 Button

| 变体 | 样式 | 用途 |
|---|---|---|
| Primary | `--brand-gradient` 底 + 白字，`--radius-lg`，高 40 | 每屏 1 个主行动 |
| Secondary | 白底 + `--border-strong` + `--text-primary` | 次要操作 |
| Ghost | 透明底 + `--text-secondary` | 表格行内操作 |
| Danger | `--danger` 底 | 删除、停用 |
| Disabled | `--bg-inset` + `--text-tertiary` + `not-allowed` + **title 写原因** | 禁用必须可解释 |

尺寸：`sm 32 / md 40 / lg 48`。图标按钮 `36×36`。

### 5.2 StatCard（**新增，解决口径问题**）

```
┌──────────────────────────────┐
│ 标注项目        [本单位] chip │  ← 标签 + 作用域
│ 47                           │  ← 大数字（tabular-nums）
│ ▁▂▃▄ 近7天  +2               │  ← 迷你趋势（可选）
│ 团队 47 · 个人 0 · 未发布 2   │  ← 一行分解
└──────────────────────────────┘
```
- `scope` 为必填属性（`SELF|TEAM|INSTITUTION|PLATFORM`），缺失时组件在开发环境抛错。
- 数值必须来自 `/api/metrics/definitions` 中登记过的 key。

### 5.3 StatusPill

```
● 已通过      →  --success / --success-bg
◑ 草稿待提交  →  --warning / --warning-bg  （hover 显示"已 25 小时未提交"）
```
高度 22，`--radius-pill`，`--fs-xs`，圆点 6px。

### 5.4 Table
- 行高 48（普通）/ 40（紧凑）；表头 `--bg-surface-2`、`--fs-xs`、`--text-secondary`、`position: sticky`。
- **一行一信息**：禁止在一格里堆三行（当前单位表格把"层级·管理员·注册时间"堆一起，v2 改三列）。
- 空状态：图标 48 + 一句解释 + 一个主行动。例："还没有项目 — 创建一个，从 30 条数据开始"。
- 批量选择后顶部浮出操作条（`--shadow-2`），显示"已选 N 项"。

### 5.5 Modal / Drawer
- Modal 宽 560（表单）/ 720（复杂）；Drawer 宽 520（从右，模型详情用）。
- 底部操作区固定：左「取消」右「主行动」；危险操作主行动为 `--danger` 且需输入对象名。
- 背景 `rgba(11,32,57,.35)` + 8px 模糊（保留现有玻璃感，但仅限弹层）。

### 5.6 Tabs（项目内页签）
- 步骤型页签带序号 `1 角色设置 2 设置 3 奖励 4 项目发布`，已完成的序号显示 ✓（现有产品已做对）。
- 之后的页签（统计/导出/任务管理器）无序号，用竖线分隔，表示"工具"而非"步骤"。

### 5.7 Progress
- 三段式：`passed`(绿) / `in_flight`(蓝) / `remain`(灰)，高 6，`--radius-pill`。
- 标签写"通过率 0%"，不写"进度 0%"。

### 5.8 Toast / InlineAlert
- Toast 右上，3s 自动消失，最多堆 3 条。
- InlineAlert 用于页面内持久提示（如"本单位尚未配置自有 OSS，配额用满后将无法上传"——现有产品已用，保留并统一为带行动按钮的样式）。

### 5.9 EmptyState
```
[图标]
还没有草稿滞留的任务
所有草稿都在 24 小时内提交，产能健康。
[查看产能看板]
```

### 5.10 Form
- Label 在上，必填用红色 `*`，帮助文案在下方 `--fs-xs` `--text-secondary`。
- 单选组超过 3 项 → 改**卡片式单选**（标题 + 一行副标题 + 图标），详细规则放 `?`。
- 错误：输入框边框 `--danger` + 下方红字，禁止只用 placeholder 提示。

### 5.11 Chart
- 折线：主线 2px、网格仅横向虚线 `--border`、无边框盒。
- 环形：内径 62%，中心放总数；图例在右，色块 8×8 圆角 2。
- 深色主题：网格 `rgba(255,255,255,.08)`，文字 `rgba(255,255,255,.65)`。

### 5.12 Canvas Toolbar（标注页）
- 保留 LS 位置（画布右上浮层 + 底部工具条），但按钮改为 v2 token（白底、`--border`、hover `--brand-primary-subtle`）。
- 底部「提交」用 `--brand-primary`（原为 LS 的深靛蓝 `#4a5b8c`，与外壳不一致）。
- 快捷键提示统一为 `kbd` 样式：`--bg-inset` 底、`--radius-sm`、`--fs-xs`。

## 六、图标与插画

- 图标：线性 1.5px，24×24 网格，圆角端点（与现有侧栏风格一致）。
- 空状态插画：单色线性 + 品牌色点缀，不用彩色 3D。
- 登录页可保留粒子/光晕动效（品牌资产），但需在 `prefers-reduced-motion` 下关闭。

## 八、深浅两主题映射

| 语义 | Light | Dark（大屏） |
|---|---|---|
| 背景 | `#F3F8FF` | `#0B2039` |
| 卡片 | `#FFFFFF` | `rgba(255,255,255,.04)` |
| 描边 | `#E3ECF7` | `rgba(255,255,255,.10)` |
| 主文字 | `#16233A` | `#FFFFFF` |
| 次文字 | `#5A6B82` | `rgba(255,255,255,.65)` |
| 主色 | `#2B91F8` | `#5CB8FF` |
| 强调数字 | `#16233A` | 渐变 `#5CB8FF → #7CF0C5` |

实现：`:root[data-theme="light|dark"]` 切换同名 token，组件不写死颜色。
