## 三、怎么用

打开 `index.html`（索引页），或直接进任意页面：

- 每个页面**右下角有深色胶囊条**，点「全部页面」可随时在 101 个状态间跳转
- 站内导航链接（左侧栏、面包屑、卡片）已接到对应本地页面
- 没有服务器依赖，双击即可（推荐 Chrome / Edge）

## 四、技术处理说明（为什么它能 1:1）

| 步骤 | 做法 | 原因 |
|---|---|---|
| DOM | 保留浏览器渲染后的完整 HTML | 与线上同一份结构，不是重写 |
| CSS | 下载 `style-*.css`（2.3 MB），并把 `url()` 里的字体/图全本地化 | 字体（Figtree）一致，字形才一致 |
| 图片 | 全部本地化（含 30 张任务缩略图、头像、模板图、证书底纹） | 断网也能看 |
| 脚本 | **全部移除** | 避免 React 重新 hydrate 破坏已渲染 DOM，也避免接口失败导致白屏 |
| `<canvas>` | 用元素截图作为背景图替代 | 标注画布是 Konva 动态绘制，静态 HTML 里必然空白 |
| 链接 | `/projects/218/tasks` → `p218-tasks.html` | 让镜像内部可导航 |
| 体积 | 大图压到长边 1200 / q82，删掉全部 js | 199 MB → 36 MB |
| 导航 | 注入右下角浮层（不在文档流里） | 不影响原布局 |

## 五、已知边界

1. **按钮不触发业务逻辑**——镜像没有 JS。这是刻意取舍：视觉 100% 一致优先于可交互。
2. **弹层是"快照"**——比如"新建数据集"弹层是打开那一刻的状态，不能填表提交。
3. **个别图片为 1×1 占位**——极少数 `<img>` 的 src 是运行时 `blob:`（前端生成的临时对象），无法下载，已替换为透明占位，不影响布局。
4. **手册页是 iframe 内嵌**——已把内嵌页 `manual-inner.html` 一并抓下来。
5. **时间戳为抓取时刻**（2026-11-14 17:00 前后），不是实时数据。
